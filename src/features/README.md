# Features Directory

Each subdirectory represents a self-contained feature module:

- `timer/` — Focus timer engine & session state machine
- `memes/` — Meme intervention system & sound triggers
- `gamification/` — XP system, level progression, and streak counters
- `sessions/` — Focus session records & history
- `statistics/` — Analytics and usage stats
- `share/` — Social sharing cards & meme export
- `settings/` — User preferences & configuration

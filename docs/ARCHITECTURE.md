# LOCKIN Documentation

## Overview
LOCKIN is a 100% local, open-source desktop break-taker application built with **Tauri 2**, **React**, **TypeScript**, **Vite**, **Tailwind CSS**, **Zustand**, and **SQLite**.

### Architecture
- **Desktop**: Tauri 2 (Rust)
- **Frontend**: React 18, Vite, TypeScript
- **Styling**: Tailwind CSS
- **State**: Zustand
- **Database**: Local SQLite (Zero cloud, 100% offline)
- **Notifications**: Tauri native notification plugin
- **System Tray**: Tauri native tray support
